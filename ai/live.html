怎麼讓這頁動起來

這頁只讀 ai/live-data.js，不會自己訓練。資料有兩種來源：
# 1) 正常訓練：ai/evolve.js 每代自動覆寫 live-data.js（推薦）
node ai/evolve.js --resume runs/warm-v2.json --gens 20

# 2) 訓練已經在跑、來不及重開：另開一個視窗監看 checkpoint
node ai/live.js --watch runs/warm-v2.json

# 只寫一次快照（不監看）
node ai/live.js --once runs/warm-v2.json
監看模式只看得到「檔案有變」，不知道訓練程序是否還活著，所以狀態會顯示「檔案監看」而不是「訓練中」。 訓練程序自己寫的那份會帶確定的 running 狀態；程序結束（含 Ctrl+C）時會寫成「已停止」。 完整訓練履歷與評判標準：ai/ledger.html。
